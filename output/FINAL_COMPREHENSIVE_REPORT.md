## 3. 개선 시도들

### 3.1 시도 1: High/Low 조기 감지 ❌ **실패**

**가설**: Close 대신 High/Low를 사용하면 더 빨리 감지 가능

**구현**:
```python
# OLD: Close 기준
if current_close > trendline_price:
    breakout!

# NEW: High/Low 기준
if current_high > trendline_price:
    breakout!  # 더 빨리 감지!
```

**결과**:

| 지표 | OLD (Close) | NEW (High/Low) | 변화 |
|------|-------------|----------------|------|
| 30봉 평균 수익률 | **+0.595%** | **-0.441%** | **-1.036%** ❌ |
| 30봉 승률 | **74.3%** | **32.3%** | **-42.0%p** ❌ |
| 10봉 승률 | **70.0%** | **27.4%** | **-42.6%p** ❌ |

**왜 실패했나?**

```
가짜 돌파 (False Breakout) 급증!

HIGH/LOW 감지:
┌────────────────┐
│      │         │  ← High가 추세선을 터치
│      ╱         │    "돌파 감지!"
│     ╱          │
│    ╱   ×       │  ← 하지만 Close는 추세선 아래
│──────────────────   (추세선)
│        ●       │  → 가짜 돌파, 즉시 손실!
└────────────────┘

CLOSE 확인:
┌────────────────┐
│          │     │
│         ╱      │  ← High 터치해도 무시
│        ╱       │
│───────●────────────  (추세선)
│      ╱         │  ← Close가 위로 마감
│                │    → 진짜 돌파 확정!
└────────────────┘
```

**교훈**: **Close 확인은 필수! High/Low만으로는 신뢰도 부족**

## 4. 진짜 문제는 무엇인가?

### 4.1 문제 재정의

초기 생각:
> "돌파 감지가 늦어서 수익이 낮다"

실제 발견:
> "돌파를 빨리 감지하려고 하면 가짜 돌파가 급증한다"

**핵심 딜레마**:
```
조기 감지 (High/Low)     vs     확정 감지 (Close)
------------------------     ------------------------
✅ 더 빨리 진입            ✅ 진짜 돌파만 포착
✅ 더 좋은 가격            ✅ 높은 승률 (74%)
❌ 가짜 돌파 급증          ❌ 일부 수익 놓침
❌ 승률 붕괴 (32%)         ❌ 돌파 전 움직임 미포착
```

### 4.2 새로운 관점

**"돌파 전 움직임"은 사실 정상!**

이유:
1. **추세선 형성 자체가 시그널**
   - 가격이 추세선에 접근할 때 이미 시장이 인지
   - 추세선 근처에서 반응 시작

2. **추세선 돌파는 "확인" 신호**
   - 돌파 = "예상했던 방향이 맞았다"는 확인
   - 확인 후에도 0.6% 수익은 충분히 의미 있음

3. **승률이 더 중요**
   - 74.3% 승률은 매우 우수
   - High/Low 방식은 수익률 개선 실패 + 승률 붕괴

## 5. 0.6% 수익률은 정말 낮은가?

### 5.1 맥락 분석

**30봉 = 7.5시간 보유**

- 7.5시간에 0.595% = 하루 1.9% = 연 694%
- 승률 74.3%
- Risk/Reward 약 2:1

**비교**:
- 대부분의 트레이딩 전략: 승률 50-60%
- 이 전략: 승률 74%

### 5.2 실제 의미

**이것은 나쁜 결과가 아니다!**

문제는:
- ❌ 수익률이 낮다
- ✅ 조기 감지하려는 시도가 실패

**합리적 기대치**:
- 추세선 돌파 후 0.6% 수익은 적절
- 승률 74%는 매우 우수
- 개선 여지는 있지만, 현 상태도 실전 가능

## 6. 최종 결론

### 6.1 사용자 질문에 대한 답변

**Q: "추세선 돌파인데 왜 평균 수익률이 0.6%밖에 안 되나?"**

**A1**: 계산은 정확함 ✅

**A2**: High/Low 조기 감지를 시도했으나 실패 ❌
- 수익률: 0.595% → -0.441% (악화)
- 승률: 74% → 32% (붕괴)
- 가짜 돌파가 너무 많음

**A3**: 품질 필터링도 효과 미미 ⚠️
- 0.595% → 0.590% (거의 변화 없음)

**A4**: **0.6% 수익률은 실제로 합리적** ✅
- 30봉 (7.5시간) 기준
- 승률 74.3%는 우수
- 추세선 돌파는 "확인" 신호이며, 확인 후에도 충분한 수익

### 6.2 핵심 교훈

1. **Close 확인은 필수**
   - High/Low만으로는 신뢰도 부족
   - 가짜 돌파 방지가 최우선

2. **조기 진입의 함정**
   - 더 빠른 진입 ≠ 더 높은 수익
   - 가짜 신호 증가로 오히려 손실

3. **품질보다 신호 타이밍**
   - 추세선 품질 높여도 수익률 거의 동일
   - 진입/청산 규칙이 더 중요

4. **합리적 기대치 설정**
   - 추세선 돌파 = 큰 수익 (X)
   - 추세선 돌파 = 높은 승률, 중간 수익 (O)

## 7. 향후 개선 방향

### 7.1 즉시 적용 가능

❌ **하지 말아야 할 것**:
- High/Low 기반 조기 진입
- Close 확인 생략
- 과도한 품질 필터링

✅ **해야 할 것**:
- 현재 시스템 유지 (Close 확인)
- 청산 규칙 최적화 (trailing stop 등)
- 진입 규모 관리 (position sizing)

### 7.2 중기 개선 (고려 사항)

1. **다단계 진입 시스템**
```python
# Level 1: 추세선 근접 (관찰만)
if distance < 0.5%:
    watch_list.append()

# Level 2: High/Low 터치 (소량 진입 고려)
if high > trendline and volume > 1.5x:
    enter_position(size=0.2)  # 20%만

# Level 3: Close 확정 (본격 진입)
if close > trendline:
    enter_position(size=0.8)  # 나머지 80%
```

2. **거래량 및 모멘텀 필터**
   - 거래량 급증 시에만 진입
   - MACD 다이버전스와 결합

3. **멀티 타임프레임 확인**
   - 상위 TF 추세 일치 시에만 진입
   - 신뢰도 향상
