```

```

### 2. 품질 필터링: **효과 거의 없음** ❌

| 필터 | 샘플 수 | 평균 수익률 | 승률 | 개선도 |
|------|---------|------------|------|--------|
| 전체 | 10,104 | **0.595%** | 74.3% | - |
| 터치 3회+ | 7,009 | **0.590%** | 74.1% | -0.005% |
| 터치 4회+ | 4,838 | **0.597%** | 74.4% | +0.002% |

**결론: 품질 필터링으로는 거의 개선 안 됨!** (0.595% → 0.613%)

### 3. 진짜 문제: **돌파 감지가 너무 늦음!** 🚨

#### 돌파 BEFORE (이미 움직인 상태)

```
돌파 전 20봉: 평균 0.417% 이미 상승
```

#### 돌파 AFTER (남은 수익)
```
돌파 후 1봉:  평균 0.040%
돌파 후 2봉:  평균 0.078%
돌파 후 5봉:  평균 0.166%
돌파 후 10봉: 평균 0.295%
돌파 후 30봉: 평균 0.595% ← 최종
```

## 💡 핵심 인사이트

### 문제 구조

```
전체 움직임: 약 1.1% (0.529% + 0.595%)

이미 움직임: 0.529% (48%)  ← 우리가 놓친 부분!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
                              ┃ 돌파 감지 시점
남은 수익:   0.595% (52%)  ←┛ 우리가 잡은 부분
```

**우리가 돌파를 감지했을 때 이미 절반은 움직인 상태!**

### 왜 늦게 감지되나?

#### 현재 돌파 감지 로직:
```python
# phase4_breakouts.py
for i in range(end_idx, search_end):
    trendline_price = get_trendline_price(trendline, i)
    current_close = df.iloc[i]['close']

    # 하락추세선 돌파
    if current_close > trendline_price:
        if prev_close <= prev_trendline:  # 이전 봉은 아래
            # 돌파 확정!
```

**문제:**
1. **Close 기준**: 종가 기준이라 이미 캔들이 끝난 후
2. **지연 확인**: 이전 봉과 비교하므로 1봉 늦음
3. **추세선 연장**: end_idx 이후만 체크 (늦은 시작)

## ⚠️ 실전 유의사항

### 조기 진입 리스크

**장점:**
- 더 높은 수익 (0.4-0.5% 추가)
- 더 좋은 진입 가격

**단점:**
- 가짜 돌파 (false breakout) 증가
- 추세선이 아직 완성 안 됐을 수도

### 권장 절충안

```python
# 추세선 근접 시
if distance < 0.5%:

if confirmed_breakout:
```
