# 돌파 감지 개선 시도 분석

생성 일시: 2025-11-27

---

## ❌ High/Low 조기 감지 실패

### 가설
- Close 대신 High/Low 사용하면 더 빨리 감지 가능
- 더 좋은 가격에 진입 가능

### 실제 결과

| 지표 | OLD (Close) | NEW (High/Low) | 변화 |
|------|------------|----------------|------|
| 30봉 평균 수익률 | **+0.595%** | **-0.441%** | **-1.036%** ❌ |
| 30봉 승률 | **74.3%** | **32.3%** | **-42.0%p** ❌ |
| 샘플 수 | 10,104개 | 10,025개 | -79개 |

### 실패 원인

**가짜 돌파 (False Breakout) 급증**

```
HIGH/LOW 감지의 문제:
┌────────────────┐
│      │         │  High가 추세선을 터치
│      ╱         │  → 돌파 감지!
│     ╱          │
│    ╱   ×       │  하지만 Close는 추세선 아래
│───────────────────  (추세선)
│        ●       │  → 가짜 돌파, 즉시 손실
└────────────────┘

CLOSE 확인의 장점:
┌────────────────┐
│          │     │
│         ╱      │  High 터치해도 무시
│        ╱       │
│───────●────────────  (추세선)
│      ╱         │  Close가 위로 마감하면
│                │  → 진짜 돌파 확정!
└────────────────┘
```

**결론: Close 확인은 필수! High/Low만으로는 신뢰도 부족**

## 🔍 진짜 문제 재분석

### 원래 발견한 문제

```
돌파 전 5봉: +0.529% 이미 움직임
돌파 후 30봉: +0.595% 남은 수익

→ 돌파 감지가 늦다!
```

### 하지만 이것이 의미하는 것은?

**Option 1: 감지 타이밍 문제? ❌**
- 더 빨리 감지 → 가짜 돌파 증가
- High/Low 사용 실패로 입증

**Option 2: 추세선 그리기 문제? 🤔**
- 추세선이 너무 늦게 완성됨
- end_idx가 이미 움직임 이후

**Option 3: 이것은 정상일 수도? ✅**
- 추세선 근처에서 가격이 먼저 반응
- 추세선 돌파는 "확인" 신호
- 0.6% 수익도 나쁘지 않음 (승률 74%)

## 💡 새로운 접근 방안

### 1. 추세선 예측 (미완성 추세선)

현재는 추세선이 완성된 후(end_idx)부터 체크:
```python
for i in range(end_idx, search_end):  # 완성 후
```

개선: 추세선이 형성되는 중에도 체크:
```python
# 2개 터치로 추세선 생성 가능
if touch_count >= 2:
    # 완성 전부터 추세선 연장
    projected_trendline = calculate_projection(touches)
```

### 2. 다중 확인 시스템

```python
# Level 1: 추세선 접근 경고 (0.5% 이내)
if distance_to_trendline < 0.005:
    alert = "approaching"

# Level 2: High/Low 터치 (예비 신호)
if high > trendline_price:
    alert = "touched"

# Level 3: Close 확정 (진입 신호)
if close > trendline_price:
    confirmed_breakout = True  # 여기서 진입!
```

### 3. 추세선 품질 개선

현재 문제:
- 추세선이 너무 많음 (10,107개)
- 품질이 낮은 추세선도 포함

개선 방안:
```python
# 최소 터치 3회 이상
min_touches = 3

# 최소 지속 기간
min_duration = 100  # 봉

# 기울기 필터 (너무 가파른 것 제외)
slope_filter = (-0.01, 0.01)  # 봉당 ±1%
```

### 4. 진입 타이밍 최적화

```python
# 돌파 확정 조건 강화
if close > trendline_price:
    if close > trendline_price * 1.002:  # 0.2% 이상 돌파
        if volume > avg_volume * 1.5:  # 거래량 증가
            # 신뢰도 높은 돌파!
            confirmed = True
```
